How it works

We don't start with a model. We start with the job.

The first question is simple: what piece of work keeps getting repeated? From there, the employee is built around the actual workflow.

The chain
Job → Context → Tools → Action → Record → Handoff

Every employee follows a chain of responsibility. That makes it possible to test the work as a workflow instead of treating AI as a magic answer box.

The right employee is usually narrower than people expect. The value comes from finishing a meaningful piece of work consistently.
01 / JOB

Identify the repetitive job.

What comes in and what does “done” mean?

02 / CONTEXT

Map what information it needs.

Files, records, rules and history.

03 / TOOLS

Connect the systems it can use.

CRM, email, documents, phone, calendar or internal systems.

04 / ACTION

Define what it is allowed to do.

Read, send, update, reconcile, call, route or prepare.

05 / RECORD

Write the result back where the team can see it.

Leave the state of the work visible and auditable.

06 / HANDOFF

Make the human boundary explicit.

Know when the job belongs to a human or another employee.
